# Multiverse-defense
The game needs a song. You must download every song you wish only 1 at the time.
The song must be .mp3 and you must rename the song as "spidey.mp3".
Save the song in the same folder as the game.
For some reasons the first fullscreen button doesn't work.
Than launch the spidey.html file to play.
Press play and have fun.

This is just a simple game, dont expect too much.
